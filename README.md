# Abhinav Sharma — Developer Portfolio

Welcome to the source code of my personal developer portfolio! 
You can view the live site here: [abhinavsharma07-eng.github.io](https://abhinavsharma07-eng.github.io/)

This is a modern, responsive single-page application built with React and Vite. It serves as my digital resume, showcasing my skills, education, and competitive coding journey.

## 🚀 Features

- **Modern UI:** Built with React and pure CSS for a clean, classic, lightweight design.
- **Live Coding Stats:** Real-time fetching of LeetCode progress using the LeetCode API.
- **GitHub Contributions:** Dynamically embeds live GitHub contribution graphs.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.
- **Automated Deployment:** CI/CD pipeline set up via GitHub Actions to automatically build and deploy to GitHub Pages on every push.

## 🛠️ Tech Stack

- **Framework:** React.js
- **Build Tool:** Vite
- **Styling:** CSS3 (Variables, Flexbox, CSS Grid)
- **Deployment:** GitHub Pages & GitHub Actions

## 💻 Local Development

Want to run this project locally? Follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/abhinavsharma07-eng/abhinavsharma07-eng.github.io.git
   cd abhinavsharma07-eng.github.io
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

## ⚙️ Deployment

The project is automatically built and deployed whenever changes are pushed to the `main` branch, utilizing the `.github/workflows/deploy.yml` GitHub Actions pipeline. The `vite.config.js` is properly configured with `base: '/'` for the `username.github.io` architecture.
